# Работа с s-ui-frontend-node

Этот репозиторий содержит Vue/Vite-интерфейс, основанный на [alireza0/s-ui-frontend](https://github.com/alireza0/s-ui-frontend). Серверная часть развивается отдельно: [serbo26-lab/s-ui-node](https://github.com/serbo26-lab/s-ui-node).

- Изменения интерфейса и переводов делай здесь; изменения Go/API — в backend.
- Не предполагай, что обновление `main` frontend автоматически обновляет backend: backend фиксирует commit SHA подмодуля `frontend/`.
- При изменении API или формата данных проверяй совместимость с соответствующей версией backend.
- Перед PR выполняй `npm ci`, `npm run lint -- --max-warnings=0`, `npx vue-tsc --noEmit`, `npm test`, `npm run build`.
- Сохраняй существующие уведомления об авторских правах и лицензию GPL-3.0.
- Не меняй установку, релизный процесс или пользовательский интерфейс ради переименования без отдельной задачи.
- В PR объясняй простыми словами, что изменено, зачем и как проверено.

## Стиль текстов

Перед публикацией README, описания PR, сообщения об изменениях, пользовательские подсказки и документацию редактируй как нормальный человеческий текст: без канцеляризма, шаблонных фраз и искусственной «нейросетевой» структуры. Пиши коротко и по существу; объясняй, что меняется, зачем это нужно и какие есть ограничения. Не украшай технические факты и не обещай проверок, которые не проводились.
